# Gotham city production sprites

The three “Gotham 2077” images supplied in chat are concept sheets. Their labels, borders, dark backgrounds, and unequal frame spacing make them unsuitable for CSS `steps()` playback.

`source/` contains the full-size transparent sprites generated from those visual references. The originals remain intact for future edits. `npm run city:assets` crops their transparent bounds, places each frame on an equal transparent cell with a fixed baseline, writes production atlases to `public/city/`, and checks dimensions, alpha, nonempty frames, and transparent cell edges.

The runtime manifest is `src/components/portfolio/city/manifest.json`. Its frame dimensions and counts must match the generated PNGs. Static buildings and street props use indexed atlas cells; fire, aircraft, ghoul, and nuclear effects use CSS `steps()` against the same geometry. The scene uses a 1920×1080 design space and scales to the viewport.

CH 02 adds the synth duel. `source/synth-duel-v1-grid.png` through `source/synth-duel-v3-grid.png` are three transparent 4×2 grids covering 24 distinct combat poses: opening exchange, sustained firefight, and close-range clash. The atlas builder preserves the cells' shared ground baseline and repacks them into `public/city/synth-duel-v2.png`, a 10752×448 horizontal strip of 24 equal 448×448 frames. The About scene plays it at four frames per second with CSS `steps(24)` behind the near building row, so the facades hide the combatants' lower bodies instead of making them stand on the roofs. The element is scaled separately, keeping the atlas texture below typical browser texture-width limits. Regenerate just this asset with `node scripts/build-city-atlases.mjs synthDuel`.

The scene has ten building families, three gap fillers, three street objects, and three walking inhabitants. Building placement uses the measured visible width of each atlas cell plus a small clear gap, so facades do not clip each other. Home, About, Work, and Projects each use a fixed seed and a different building mix to create a stable district. Seeded prop groups place scrub, rubble, fences, barricades, lamps, terminals, fires, and wrecked vehicles on the rear and middle ground planes. Walking characters and a terminal interaction vignette vary by district. The shallow curb, road markings, distant structures, smoke, clouds, rain, and searchlights are CSS layers so they can scale cleanly with the 1920×1080 world.

The terrain includes a full panoramic wasteland backdrop, dead scrub, a wrecked bus, a destroyed supply truck, and a broken highway sprite. Two opaque, textured ruined-earth planes sit between the building rows, each with drifting smoke over its surface; only a thin curb and road run across the foreground. Structural scenery remains stationary. Clouds, rain, searchlights, window beacons, fire, fallout dust, and characters animate, while a low-resolution WebGL pass supplies rolling fog, smoke plumes, and ash flecks. Far and middle buildings stay fully opaque; CSS blur/lighting creates depth of field. `source/wasteland-backdrop.png` is the full-size source; `public/city/wasteland-backdrop.png` is the runtime copy.

To replace an asset, keep its source filename or update `scripts/build-city-atlases.mjs`, regenerate the atlases, inspect the resulting strip, and run the site build. Source images should have transparent alpha and a single isolated subject or one evenly spaced horizontal row of frames. The atlas builder also checks that animation strips contain distinct frames.
